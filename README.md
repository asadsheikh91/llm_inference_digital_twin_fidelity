# Fidelity Floors for Digital Twins of LLM Inference Clusters

**Research question:** How much operator-level fidelity does a digital twin of an LLM inference cluster require before its serving decisions (replica count, batch size cap, tensor-parallel degree, model placement) become indistinguishable from those of a perfect-information oracle, and what profiling cost does additional fidelity beyond that point incur?

Course research project, FAST NUCES Islamabad, 2026.
Authors: Asad Amad, Ahyan Ali Khan
